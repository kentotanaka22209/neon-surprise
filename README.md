# ネオン光弦 (NeonSurprise)

**「ネオン光弦 (NeonSurprise)」**は、暗闇の宇宙空間を指でなぞって**弾力のある光の弦（ネオンストリング）**を張り、降り注ぐ「光のしずく」を弾いて跳ね返しながら連鎖反応を楽しむ、インタラクティブな物理おもちゃ×チェインゲームです。弦にしずくが当たると琴やギターの弦のようにしなって振動し、波紋と火花がはじけ、色とコンボ倍率をまとったしずくが分裂プリズムや共鳴花（ネオンブルーム）へと飛び込んで大輪の花火のように開花します。10秒で直感的に遊べる8つの星座ミッション＆エンドレス連鎖の「プレイ」モードに加え、無重力やプリセット造形を自由に組める「光の庭園（サンドボックス）」、さらにプレイ実績で解放され指で突いて遊べるアニメーション付き「ネオン図鑑＆しずくスキン」の3つのモードを備え、音を使わず振動アニメーションと光彩エフェクトだけで心地よい手触りを体験できます。

---

## 遊び方・機能

### 1. プレイ（星座ミッション & エンドレス連鎖）
- **指でドラッグして光の弦を張る**: 降ってくる「光のしずく」の通り道に弦を張ると、しずくが弾かれて跳ね返ります。
- **3種類の光の弦**:
  - **共鳴弦**: バランスよく軽やかに反発します。
  - **加速弦**: しずくを勢いよく高く打ち上げます。天井付近の花に届かせたいときに活躍！
  - **虹の弦**: しずくを虹色チャージ状態にし、共鳴花に当たったときにボーナスしずくを追加放出します。
- **ギミック**:
  - **分裂プリズム**: しずくが通過すると2つの虹色しずくに分裂します。
  - **引力玉**: 周囲を通るしずくの軌道をぐるっと曲げます。
  - **弦を直接タップ**: 張った弦を指で直接はじいて、近くのしずくをふわりと揺らすこともできます。
- **2つのサブモード**:
  - **星座ミッション**: 全8ステージのネオン星座パズル。すべての共鳴花を咲かせるとクリア！
  - **エンドレス**: ウェーブごとに新しい星座が出現。コンボを重ねてゲージを満たすと**FEVER TIME（スコア2倍＆虹色の流星群）**が発動します。

### 2. 光の庭園（サンドボックス）
- スコアやクリア条件にとらわれず、自由に光の装置を作って眺められるクリエイティブモードです。
- **5つのツール**: `光の弦` / `プリズム` / `引力玉` / `花火花` / `しずく（指で虹色のしずくを散布）`
- **物理＆テンポ切替**: `通常重力` / `ふわふわ` / `無重力`（画面の四辺すべてで永久反射！）と、発射テンポをリアルタイム変更できます。
- **5つのネオンテーマ**: `サイバー東京` / `夜桜ネオン` / `深海ホタル` / `夏祭り花火` / `オーロラ氷河`
- **4つのプリセット造形**: `無限トランポリン` / `虹の滝` / `無重力オルゴール` / `万華鏡ピンボール` をワンタップで呼び出して改造できます。

### 3. 図鑑・記録（ネオン光標本 & しずくスキン）
- ハイスコア・最大コンボ・総はじき回数・開花数・プリズム分裂数・クリア星座数は端末内に自動保存（`@AppStorage`）されます。
- **しずくスキン（全5種）**: 実績に応じて「星のしずく」「ダイヤ結晶」「ネオン桜びら」「彗星スパーク」「ハート花火」が解放・装備できます。
- **ネオン光標本（全12種）**: 解放された標本をタップすると詳細画面が開き、画面上の光標本を指でつついたり引っ張ったりして弾力アニメーションと光パルスを楽しめます。

## ビルド方法

### 動作環境・仕様
- **SwiftUI** のみ（`SwiftUI` + `Foundation` / 外部依存ゼロ / 権限不要 / ネットワーク不要）
- **iOS 17.0+** / Swift 5.9+
- プロジェクト: `NeonSurprise.xcodeproj` / スキーム: `NeonSurprise` / Bundle ID: `com.mango.neonsurprise`

### GitHub Actions での自動ビルド
リポジトリに push するか、GitHub の **Actions** タブから `Build NeonSurprise iOS` ワークフローを実行すると、`macos-15` 上で自動ビルドされ、`NeonSurprise-unsigned-ipa` アーティファクト（`NeonSurprise-unsigned.ipa`）が生成されます。

### ローカル（macOS + Xcode）でのビルド
1. `NeonSurprise.xcodeproj` を Xcode で開きます。
2. コマンドラインから未署名ビルドする場合は以下を実行します:
   ```bash
   xcodebuild \
     -project NeonSurprise.xcodeproj \
     -scheme NeonSurprise \
     -destination 'generic/platform=iOS' \
     -derivedDataPath build \
     CODE_SIGNING_ALLOWED=NO \
     CODE_SIGNING_REQUIRED=NO \
     build
   ```
3. 未署名 IPA のパッケージング:
   ```bash
   mkdir -p Payload
   cp -r build/Build/Products/Debug-iphoneos/NeonSurprise.app Payload/
   zip -r NeonSurprise-unsigned.ipa Payload
   ```

## 実機インストール時の注意（未署名 IPA について）

GitHub Actions で生成される `NeonSurprise-unsigned.ipa` は**未署名（Unsigned）**です。そのままでは iPhone / iPad にインストールできないため、実機へ入れる際は以下のいずれかの方法で再署名（Re-sign）してください。

- **SideStore / AltStore / Sideloadly** などのサイドロードツールを使い、ご自身の Apple ID で再署名してインストールする
- Xcode で `NeonSurprise.xcodeproj` を開き、Signing & Capabilities でご自身の Team を設定して実機へ直接ビルド・実行する
